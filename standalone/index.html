Compare the behavior

  1. Open a standalone app and its original in separate tabs. Original links require the full-stack services to be running locally.
  2. Open a standalone app. Its full-stack original needs Rails, PostGIS, Redis and Sidekiq, so it runs only from a local checkout of the project, not from this site.
  3. Perform the same workflow in each. Standalone changes never reach the original databases.
  4. Reload the standalone app to check saved data. Switch demo roles to compare the visible workflow.
  5. Export a result, then use Reset demo data to return that standalone app to its initial examples.

Browser processing ends when the page closes. Local history and simulated permissions are editable browser data. Spherical distance/area/profile methods can differ from PostGIS ellipsoidal results. These are synthetic learning applications, not operational systems.
